# WAVOO

NAVER Whale × HUFS — HUFS 학생을 위한 웨일 사이드바 확장앱

## 프로젝트 개요

WAVOO는 네이버 웨일 스토어에서 설치하는 하나의 사이드바 확장앱입니다.
외대 학생들이 자주 사용하는 검색, 공지 확인, 학교 사이트 접속, 전공 언어권 뉴스 확인, 시간표/알림 기능을 브라우저 옆 하나의 사이드바에 통합하는 것을 목표로 합니다.
화면은 세로형 웨일 사이드바 UI를 기준으로 구성하며, 실제 사이드바 폭 변화에도 대응할 수 있도록 반응형으로 설계합니다.

## 핵심 기능

WAVOO는 총 5개의 주요 기능으로 구성합니다.

**OQMA**
- 하나의 검색어로 번역, 예문, 이미지, AI 결과 등을 비교
- 기존 OQMA 시제품을 WAVOO 내부 핵심 기능으로 통합
- 추후 단어장 저장 기능과 연결

**공지 키워드 알림**
- 장학, 교환학생, 인턴 등 사용자가 등록한 키워드 기반 공지 확인
- 새 공지가 조건에 맞을 때만 알림 제공

**학교 사이트 링크 모음**
- HUFS Portal, e-Class, 도서관, HUFSAbility, 증명서 발급 등
- 자주 사용하는 학교 사이트를 한 곳에서 빠르게 실행

**학과별 맞춤 뉴스**
- 사용자의 학과/전공 언어권에 맞는 뉴스를 사이드바에서 제공
- 예: 말레이·인도네시아어과 → 인도네시아/말레이시아 관련 뉴스

**BOO**
- 시간표, 공지 마감일, 접속 기록 등을 캐릭터 말풍선 형태로 전달
- 다른 기능이 수집하거나 저장한 정보를 사용자 친화적으로 보여주는 역할

## 디렉터리 역할

- **app** — WAVOO 전체 사이드바 프레임과 화면 이동. 공통 레이아웃, 헤더, 네비게이션 관리
- **features** — 5개 핵심 기능을 각각 독립 모듈로 관리 (oqma / notice / links / news / boo)
- **extension** — background 동작, 브라우저 알림, 페이지 정보 읽기, 메시지 통신, 권한 관리
- **services** — 외부 데이터 연결 (검색 API, 공지, 뉴스). UI와 외부 데이터 연결 코드를 분리
- **storage** — 사용자 데이터 로컬 저장 (시간표, 공지 키워드, OQMA 단어장, 설정, 접속 기록). 개인 정보는 서버가 아닌 로컬 저장 우선
- **components** — 여러 기능에서 공통으로 쓰는 UI (버튼, 카드, 모달, 네비게이션)
- **assets** — 로고, BOO 캐릭터, 아이콘, 이미지

## 개발 기본 원칙

1. 기능별로 분리해서 작업 — 2인 동시 개발이므로 기능별 디렉터리를 최대한 독립적으로 유지
2. UI와 데이터 연결 로직 분리 — 화면은 features, 외부 연결은 services
3. 사용자 데이터는 로컬 우선 — 시간표, 키워드, 단어장, 접속 기록 등은 서버보다 로컬 저장 우선
4. 공통 UI는 중복 생성하지 않기 — components에 공통화
5. OQMA는 별도 앱이 아니라 WAVOO 내부 기능 — features/oqma 안으로 통합

## 2인 협업 기준

**공동 작업**: manifest.json, app/, 공통 components/, 공통 types/, storage 규칙, Git 브랜치/merge 규칙

- **개발자 A 예시**: OQMA, 검색 서비스, 단어장, 뉴스
- **개발자 B 예시**: 공지 알림, 학교 링크, BOO, background 알림

역할 분담은 실제 구현 순서에 따라 변경할 수 있습니다.

## 우선 구현 순서

1. WAVOO 기본 사이드바 프레임
2. 하단/상단 탭 네비게이션
3. 학교 링크 기능
4. 기존 OQMA 기능 통합
5. 공지 키워드 알림
6. 학과별 뉴스
7. BOO
8. 전체 기능 통합 및 웨일 스토어 제출 준비

## 개발 환경

```bash
npm install
npm run dev     # 개발 빌드 (watch)
npm run build   # 프로덕션 빌드 → dist/
```

`dist/` 폴더를 웨일 브라우저의 `chrome://extensions` → 개발자 모드 → "압축해제된 확장 프로그램 로드"로 불러와서 테스트합니다.
